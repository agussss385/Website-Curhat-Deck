# 🌟 CurhatDeck - Gen-Z Venting & Counseling Website

Website platform curhat dan konseling mahasiswa berbasis AI (Gemini AI API) dan Konseling Privat 1-on-1.

## 🚀 Cara Menjalankan Project di VS Code:

1. Buka folder `curhatdeck` di **Visual Studio Code**.
2. Install ekstensi **Live Server** di VS Code (jika belum ada).
3. Klik kanan pada file `index.html` dan pilih **Open with Live Server**.
4. Website siap diakses di browser!

## 🔐 Fitur & Panduan Akses:
- **Mode Mahasiswa (Default):** Fitur Chat AI 24/7 (CurhatBuddy) & Formulir Booking Sesi Konseling.
- **Mode Konselor:** Klik tombol **"Login Konselor"** di kanan atas.
  - **Password Login:** `admin123`
  - Fitur: Kelola antrean booking (Approve/Selesai/Hapus) dan atur Status Konselor (Online/Sibuk/Offline).
